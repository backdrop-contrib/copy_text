Copy Text
============================

This module creates Javascript that puts an icon after text wrapped with the `copy-text` class that, when clicked, copies the text to the clipboard.

Installation
------------

- Install this module using [the official Backdrop CMS instructions](https://backdropcms.org/guide/modules).

Usage
------------

Wrap the text to be copyable in `<span class="copy-text">...</span>` tags and the icon will appear as a button immediately after the text.
